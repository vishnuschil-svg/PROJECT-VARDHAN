# AI Chit OS Blueprint

MITRA NIDHI CHITI PRO is being upgraded from a fixed monthly chit model to a schedule-driven, rule-driven, template-driven and AI-assisted chit operating system.

Primary flow:

Repository -> Domain Engine -> Service -> Context/UI

New primary model:

Chit Group -> Chit Template -> Rule Set -> Month-wise Schedule -> Member State -> Payable Resolution -> Ledger -> Finance -> Reports

External AI/OCR is not connected in Version 1.0. Local/manual providers are used and owner confirmation is mandatory.
