# MITRA NIDHI CHITI PRO Receipt Engine

## Receipt Workflow

Receipts use the existing Receipts route and collection success flow.

```text
Collection Success
-> Generate Receipt Number
-> Validate Receipt
-> Save Receipt Record
-> Preview Receipt
-> Print Receipt
-> Download PDF-ready Layout
-> Create Image-ready Layout
-> WhatsApp Share Fallback
-> Show Receipt History
-> Track Reprint
```

## Receipt Number Rules

Receipt numbers are generated by `src/receipts/ReceiptNumberEngine.js`.

Format:

```text
MNCP-RCP-YYYYMMDD-0001
```

Rules:

- Date is based on receipt generation date.
- Sequence is checked against existing tenant receipt numbers.
- Duplicate numbers are skipped before a receipt model is returned.
- Duplicate receipt validation still runs before save.

## Validation Rules

Validation lives in `src/receipts/ReceiptValidator.js`.

Rules covered:

- Duplicate receipt number.
- Missing collection.
- Missing member.
- Missing group.
- Invalid amount.
- Invalid receipt date.
- Cancelled receipt protection.
- Reprint history warning.

Errors block save/reprint. Warnings are returned to the service for display or operational review.

## Repository Flow

```text
src/repositories/ReceiptRepository.js
-> src/repositories/chits/ReceiptsRepository.js
-> src/repositories/chits/CollectionsRepository.js
-> src/repositories/chits/MembersRepository.js
-> src/repositories/chits/GroupsRepository.js
```

The repository normalizes saved receipt models and older collection-derived receipt records into one production receipt model for the UI.

## Service Flow

Location: `src/services/receiptService.js`

Key functions:

- `generateReceipt()`
- `listProductionReceipts()`
- `getReceiptPageModel()`
- `getReceiptActions()`
- `trackReceiptReprint()`

The service is the only UI-facing API. React components do not calculate receipt totals, receipt numbers, validation state, print payloads, PDF-ready payloads, or WhatsApp URLs.

## Print / PDF / WhatsApp Behavior

- Preview: `ReceiptPreview` renders HTML generated by `ReceiptEngine`.
- Print: `ReceiptPrint` creates a print-ready HTML document and tracks reprints through the repository.
- PDF/download: `ReceiptPDF` returns a PDF-ready HTML layout for browser download.
- Image: `ReceiptImage` creates an SVG image-ready receipt layout.
- WhatsApp: `ReceiptWhatsApp` creates a safe `wa.me` fallback link with receipt summary text.

## Owner Bank Details And Footer

Owner bank details and footer note are provided by `ReceiptRepository.getReceiptSource()` so future Supabase tenant settings can replace the current local repository values without changing UI components.

## Known Limitations

- The current PDF output is browser-downloadable PDF-ready HTML, not a server-rendered archival PDF.
- Image output is SVG-ready for sharing fallback; production raster conversion can be added behind `ReceiptImage`.
- WhatsApp uses a `wa.me` fallback link; future WhatsApp API integration should attach behind `ReceiptWhatsApp`.
- Receipt persistence is local repository backed today; Supabase can attach at the repository boundary.
