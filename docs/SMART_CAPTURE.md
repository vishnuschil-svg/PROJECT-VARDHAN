# Smart Capture

Smart Capture is exposed through Dashboard Quick Actions and Chit Studio import mode.

Supported UI actions:

- Upload Chit Photo
- Upload PDF
- Import Excel
- Drag and drop
- File picker
- Editable extracted fields
- Confidence indicators
- Save draft
- Create Chit Group

Current mode:

Manual Capture Mode - AI/OCR provider is not connected. Upload is preserved for reference; enter or paste extracted values and verify every field.
