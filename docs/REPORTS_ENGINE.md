# MITRA NIDHI CHITI PRO Reports Engine

## Available Reports

The production Reports route supports:

1. Business Summary
2. Daily Collection Report
3. Weekly Collection Report
4. Monthly Collection Report
5. Yearly Collection Report
6. Pending Collection Report
7. Member Ledger
8. Member Passbook
9. Chit Group Summary
10. Auction Report
11. Lucky Draw Report
12. Receipt Register
13. Cash Book Report
14. Bank Book Report
15. Income Report
16. Expense Report
17. Commission Report
18. Profit Report
19. Inactive Members Report
20. Top Paying Members
21. Staff Collection Report

## Data Sources

Reports use the same repository data as the operational modules:

- Collections: `src/repositories/chits/CollectionsRepository.js`
- Receipts: `src/repositories/chits/ReceiptsRepository.js`
- Finance: `src/repositories/chits/FinanceRepository.js`
- Members: `src/repositories/chits/MembersRepository.js`
- Groups: `src/repositories/chits/GroupsRepository.js`
- Auctions: `src/repositories/chits/AuctionRepository.js`
- Saved reports: `src/repositories/ReportsRepository.js`

The UI consumes `src/services/reportsService.js`. React components do not calculate report totals or reconciliation state.

## Filter Rules

Filters are normalized in `src/reports/ReportFilters.js`.

Supported filters:

- Date range
- Chit group
- Member
- Staff
- Payment mode
- Collection status
- Receipt status
- Amount range
- Active / completed group status

Invalid date ranges and missing group/member references are reported by `ReportValidator`.

## Export Behavior

Exports are generated by `src/reports/ReportExport.js`.

Supported ready formats:

- Print
- CSV
- Excel-ready HTML export
- PDF-ready HTML layout

Email and WhatsApp remain future channels and are disabled where surfaced.

## Reconciliation Rules

`src/reports/ReportValidator.js` adds consistency checks for:

- Invalid date range
- Missing group
- Missing member
- Empty report handling
- Closed month consistency
- Duplicate receipt consistency
- Ledger mismatch detection
- Collection total vs finance total mismatch

Validation errors and warnings are shown in the Reports route and travel with the generated report model.

## Known Limitations

- PDF output is browser-downloadable PDF-ready HTML, not server-rendered archival PDF yet.
- Excel output is spreadsheet-openable HTML, not native XLSX generation.
- Pagination depends on the shared table component; server-side pagination can be added at the repository boundary.
- Supabase integration can replace local repositories without changing UI components.
