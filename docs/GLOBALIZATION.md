# Globalization

Localization support is available through `localizationService`, `LocaleContext`, and locale configs.

## Supported Locales

`en-IN`, `te-IN`, `hi-IN`, `ta-IN`, `kn-IN`, `en-US`.

## Supported Currencies

INR and USD are represented through locale settings.

## Rule

Money and date display must use service/context formatting, not component-side string concatenation.
