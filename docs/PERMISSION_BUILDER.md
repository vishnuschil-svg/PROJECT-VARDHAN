# Permission Builder

Granular permissions are built with `permissionBuilderService`.

## Resources

Dashboard, batches, groups, members, collections, pending, auctions, lucky draw, payouts, receipts, ledger, finance, expenses, investors, reports, import, AI studio, templates, settings, communication, and audit.

## Actions

View, create, edit, cancel/delete, approve, export, print, share, close period, reopen period, override, and manage permissions.

## Rule

Feature UI must check service output before enabling privileged actions.
